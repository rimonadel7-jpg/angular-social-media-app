## ✨ Features

### 🔐 Authentication & Security
- **User Registration & Login**: Secure JWT-based authentication.
- **Route Guards**: Protect private routes (feed, profile, create post).
- **HTTP Interceptors**: Auto-attach auth tokens and handle errors globally.
- **Session Management**: Auto-logout and token refresh handling.

### 📰 Feed & Posts
- **Create Posts**: Share text and images with the community.
- **Dynamic Feed**: View posts from all users with real-time updates.
- **Post Interactions**: Like and unlike posts with instant UI updates.
- **Comments**: Add and view comments on posts.

###  User Profile
- **View Profile**: See user's personal posts and details.
- **Edit Profile**: Update user information and profile picture.
- **User Posts**: Filter and view specific user's activity.

### 🎨 UI/UX
- **Fully Responsive**: Mobile-first design using Bootstrap 5.
- **Modern Angular**: Using Standalone Components and modern routing.
- **Loading States**: Smooth loading indicators for better UX.

## 🛠️ Tech Stack
- **Frontend Framework**: Angular 17+
- **State Management**: RxJS (BehaviorSubject, Observables)
- **Styling**: Bootstrap 5
- **HTTP Client**: Angular HttpClient
- **Forms**: Reactive Forms with Validation
- **Deployment**: Vercel

## 📦 Installation & Setup

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Clone & Install
```bash
# Clone the repository
git clone https://github.com/rimonadel7-jpg/angular-social-media-app.git

# Navigate to project directory
cd angular-social-media-app

# Install dependencies
npm install

# Run development server
ng serve
```
